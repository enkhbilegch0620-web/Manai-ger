# Manai-ger
Гэр бүлийн гэрийн ажил, хуваарь, захиалгын систем

Next.js 16 + Tailwind CSS 4. Дараа нь Supabase-тай холбоно.

## Ажиллуулах

```bash
npm install
npm run dev
```

Хөтөч дээр http://localhost:3000 хаягийг нээнэ. Нэвтрэх хуудас: http://localhost:3000/login

Туршилтын нэрс: **Ээж**, **Тувшин**, **Админ** (PIN `1234`). **Аав** анх нэвтэрч байгаа тул PIN үүсгэнэ.

## Хуудсууд

| Хаяг | Хуудас | Төлөв |
|---|---|---|
| `/login` | Нэвтрэх: нэр → PIN, анх удаа бол PIN үүсгэх | 1-р долоо хоног ✅ |
| `/setup` | Анхны админ үүсгэх | 1-р долоо хоног ✅ |
| `/` | Нүүр: өдрийн тойм | 1-р долоо хоног ✅ |
| `/profile` | Ажил / Сурагч: 7 хоногийн хуваарь, төлөвлөгөө | 1-р долоо хоног ✅ (цонхнууд 3-р долоо хоногт) |
| `/chores` | Гэрийн ажил: ажил өгөх, засах, устгах | 2-р долоо хоног ✅ |
| `/shop` | Захиалга: нэмэх, авсан гэж тэмдэглэх, устгах, цэвэрлэх | 2-р долоо хоног ✅ |
| `/schedule` | Хуваарь | 3-р долоо хоног |
| `/admin` | Админ хэсэг | 4-р долоо хоног |

## Файлын бүтэц

```
app/
  layout.tsx            бүх хуудсанд нийтлэг (фонт, өнгө)
  (auth)/               дэлгэцийн голд карттай хуудсууд
    login/  setup/
  (main)/               дээд цэстэй хуудсууд
    layout.tsx          AppHeader + голын багана
    page.tsx            Нүүр (HomeView.tsx)
    profile/ chores/ shop/ schedule/
  admin/
components/
  ui.tsx                Button, Field, Card, Avatar, Tag (Figma-гийн component-ууд)
  Modal.tsx             цонх, баталгаажуулах цонх
  AppHeader.tsx         дээд цэс
lib/
  mock-data.ts          ЖИШЭЭ өгөгдөл — Supabase-ээр солигдоно
  store.tsx             хуудсууд хооронд хуваалцах жишээ төлөв (ажил, захиалга)
  useToday.ts           өнөөдрийн огноо, огнооны туслах функцууд
```

Өнгөнүүдийг `app/globals.css` дотор тодорхойлсон: `bg-bg`, `text-muted`, `border-line`, `bg-dark` гэх мэт.
